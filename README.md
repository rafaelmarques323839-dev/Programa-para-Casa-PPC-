## 🎯 Motivação
Este repositório armazena as implementações computacionais desenvolvidas para a disciplina de Cálculo Numérico Aplicado. O objetivo é construir algoritmos "do zero", sem o uso de caixas-pretas, para resolver problemas físicos e matemáticos da engenharia, garantindo a reprodutibilidade e a transparência do código (filosofia Open Source).

## 📁 Topologia do Repositório
O repositório está organizado em diretórios isolados para cada prática:

* `PPC_01/`: Contém a resolução do problema de sedimentação de uma partícula (Equações Diferenciais Ordinárias).
  * `README.md`: Documentação específica da prática, com dicionário de variáveis e validação.
  * `ppc_1_(python).py`: Script principal com a implementação do método de Runge-Kutta (RK4).
